# 공문 어투 바꾸기 (양방향)

두 가지 방향이 있습니다. 사용자의 요청으로 방향을 정하고, 분명하지 않으면 입력이 이미 공문 형식이면 **풀어 쓰기**, 아니면 **공문으로 쓰기**로 봅니다.

## A. 일반 글 → 공문

### 지킬 규칙

1. **내용을 더하지 않습니다.** 원문에 없는 날짜, 기관명, 담당자, 연락처, 근거 법령, 문서번호를 만들지 않습니다. 공문에 필요한데 원문에 없으면 `(작성 필요)`로 둡니다.
2. **두문은 칸만 둡니다.** 수신, 참조, 제목을 위에 두고, 원문에 없는 칸은 `(작성 필요)`로 둡니다.
3. **본문 첫 항목은 관련 근거 또는 인사.** 원문에 관련 문서가 있으면 `1. 관련: ...`으로 시작하고, 없으면 `1. 귀 기관의 무궁한 발전을 기원합니다.` 같은 인사 한 줄로 시작합니다.
4. **요청 문장은 공문 어투로.** 「~하고자 하오니」, 「~하여 주시기 바랍니다」, 「~을 알려 드립니다」, 「~에 대하여 협조를 요청합니다」처럼 씁니다. 「~해 주세요」, 「~할게요」 같은 말투는 바꿉니다.
5. **항목 번호는 1. → 가. → 1) → 가) 순서.**
6. **날짜와 시간 표기.** 날짜는 `2026. 10. 8.`처럼 연, 월, 일 글자를 빼고 숫자 뒤에 온점을 찍고 한 칸씩 띕니다. 요일은 `2026. 10. 8.(목)`처럼 붙입니다. 시간은 `14:00`처럼 24시각제로 씁니다. 원문 날짜에 연도가 없으면 연도를 지어내지 않고 `10. 8.`로 둡니다. 요일이 원문에 없으면 요일을 계산해 넣지 않습니다.
7. **붙임과 끝 표시.** 첨부가 있으면 본문 아래에 `붙임  1. 자료명 1부.`처럼 적고, 마지막 붙임 뒤에 두 칸 띄우고 `끝.`을 씁니다. 첨부가 없으면 본문 마지막 문장 뒤에 두 칸 띄우고 `끝.`을 씁니다. 원문에 첨부 언급이 없으면 붙임을 만들지 않습니다.
8. **금액 표기.** 원문에 금액이 있으면 `금1,500,000원(금일백오십만원)`처럼 숫자와 한글을 함께 쓰는 형식을 제안하되, 숫자는 원문 그대로 씁니다.

### 출력 형식

```
수신  (작성 필요 또는 원문의 수신처)
(경유)
제목  ...

1. ...
2. ...하고자 하오니 ...하여 주시기 바랍니다.
  가. 일시: 2026. 10. 8.(목) 14:00
  나. 장소: ...

붙임  1. ...  1부.  끝.

※ 작성 필요 칸: ...
```

## B. 공문 → 쉬운 말

### 지킬 규칙

1. **맨 위에 「그래서 내가 할 일」 한두 줄.** 무엇을, 언제까지, 누구에게 해야 하는지만 먼저 씁니다. 해야 할 일이 없는 알림 공문이면 `할 일 없음(알림)`이라고 씁니다.
2. **기한과 숫자는 원문 그대로.** 날짜를 다른 형식으로 바꿀 때도 값은 바꾸지 않습니다.
3. **어려운 말은 괄호로 풀어 줍니다.** 예: 「회신(답장)」, 「제출(보내기)」, 「경유(거쳐서)」, 「붙임(첨부)」.
4. **원문에 없는 해석은 하지 않습니다.** 불이익, 법적 효과처럼 원문에 없는 내용은 쓰지 않고, 애매하면 `보낸 곳 담당자에게 확인 필요`라고 씁니다.

### 출력 형식

```
## 그래서 내가 할 일
- ...

## 쉬운 말로 풀면
- ...

## 기한과 제출처
- 기한: (원문 그대로, 없으면 원문에 기한 없음)
- 제출처: ...

## 확인이 필요한 것 (있을 때만)
- ...
```

## 예시

`예시/입력_일반글.md`와 `예시/기대출력.md`를 참고합니다(모두 가상 데이터).
