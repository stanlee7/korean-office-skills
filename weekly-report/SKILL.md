# 한 주 메모 → 주간보고 초안

한 주 동안의 메모나 할 일 목록을 받아 **주간보고 초안**을 만듭니다.

## 지킬 규칙

1. **숫자는 원문에 있는 것만 씁니다.** 건수, 금액, 비율, 날짜를 새로 만들거나 계산해 부풀리지 않습니다. 원문에 숫자가 없으면 숫자 없이 씁니다.
2. **없는 일을 만들지 않습니다.** 메모에 없는 성과, 다음 주 계획, 이슈를 지어내지 않습니다. 다음 주 계획이 메모에 없으면 `메모에 없음(작성 필요)`이라고 씁니다.
3. **회사 양식이 있으면 양식이 먼저입니다.** 사용자가 양식(칸 이름, 순서, 예시)을 주면 그 칸 이름과 순서를 그대로 쓰고, 아래 기본 형식은 쓰지 않습니다. 양식 칸에 넣을 내용이 메모에 없으면 그 칸은 `작성 필요`로 둡니다.
4. **개조식으로 짧게 씁니다.** 한 줄에 한 가지, 「~함」, 「~ 완료」, 「~ 예정」처럼 끝냅니다.
5. **끝나지 않은 일은 「진행 중」으로 표시합니다.** 완료 여부가 메모에서 분명하지 않으면 `진행 중(확인 필요)`로 씁니다.
6. **회사 기밀과 개인정보는 넣지 않도록 알립니다.** 메모에 고객 연락처, 주민번호 같은 개인정보가 보이면 초안에서는 `[개인정보 삭제]`로 바꾸고 맨 끝에 한 줄로 알려 줍니다.

## 기본 형식 (회사 양식이 없을 때)

```
# 주간보고 (기간: 원문에 있는 날짜, 없으면 "기간 작성 필요")

## 1. 이번 주 한 일
- [완료] ...
- [진행 중] ...

## 2. 다음 주 계획
- ...

## 3. 이슈와 요청
- 이슈: ...
- 요청: (누구에게, 무엇을)
```

이슈나 요청이 메모에 없으면 `특이 사항 없음`이라고 씁니다.

## 예시

`예시/입력_한주메모.md`와 `예시/기대출력.md`를 참고합니다(모두 가상 데이터).
