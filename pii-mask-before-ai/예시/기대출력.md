# 예시 기대 출력

> 가상 데이터로 만든 예시입니다. 실제 결과는 입력과 모델에 따라 조금씩 다를 수 있습니다.

> 주의: 이 스킬도 AI 안에서 돌아가므로 원문은 이미 이 대화에 들어왔습니다. 외부 AI에 넣으면 안 되는 자료라면 회사가 허용한 로컬 도구로 가리세요.
> 이름, 주소처럼 형식이 없는 정보는 놓칠 수 있으니 넘기기 전에 한 번 읽어 확인하세요.

## 1. 가린 글 (이것만 AI에 넣으세요)

```
10/7 환불 문의 정리
- [이름1] 고객님([전화1], [메일1]) 9월 주문 건 환불 요청
- 결제 카드 [카드1] 으로 취소 원하심, 안 되면 계좌 환불 희망: 국민은행 [계좌1]
- 법인 구매라 사업자번호 [사업자번호1] 으로 세금계산서 재발행 필요
- 본인 확인용으로 주민번호 [주민번호1] 를 보내셨는데 이건 받으면 안 되는 정보라 파기 안내 필요
- 주소: [주소1] (반품 회수지)
- 담당: 우리팀 [이름2], 회신은 [전화1] 로 문자
- 주문번호 20260907-0042
```

## 2. 되돌리기 표 (내 컴퓨터에만 보관, AI에 넣지 마세요)

```
| 표시 | 원래 값 | 종류 | 확인 |
|---|---|---|---|
| [이름1] | 홍길동 | 이름 | |
| [이름2] | 박과장 | 이름 | 사내 담당자, 직급까지 가림 |
| [전화1] | 010-1234-5678 | 전화 | 두 번 나옴 |
| [메일1] | gildong@example.com | 이메일 | |
| [카드1] | 1234-5678-9012-3456 | 카드번호 | |
| [계좌1] | 123456-78-901234 | 계좌 의심 | |
| [사업자번호1] | 123-45-67890 | 사업자번호 | |
| [주민번호1] | 123456-1234567 | 주민번호 형식 | |
| [주소1] | 서울시 가상구 예시로 12 | 주소 | |
```

## 3. 직접 확인할 곳

- 「[주민번호1]」: 받으면 안 되는 정보입니다. 되돌릴 일이 없으면 되돌리기 표에서도 지우고 원본에서 삭제하세요.
- 「우리팀」: 팀 이름이 없어 그대로 두었습니다. 실제 팀명을 덧붙였다면 확인하세요.
- 「주문번호 20260907-0042」: 주문번호로 보여 가리지 않았습니다. 고객을 특정할 수 있으면 가리세요.
