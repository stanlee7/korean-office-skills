# AI에 넣기 전 개인정보 가리기

받은 글에서 개인정보를 찾아 **가린 글**과 **되돌리기 표**를 따로 만듭니다. 가린 글만 AI나 다른 사람에게 넘기고, 되돌리기 표는 사용자 컴퓨터에만 둡니다.

## 꼭 알려 줄 것 (출력 맨 위에 항상)

- 이 스킬도 AI 안에서 돌아갑니다. **원문을 붙여 넣은 순간 원문은 이미 이 대화에 들어온 것**입니다. 회사 규정상 외부 AI에 원문을 넣으면 안 되는 자료라면, 이 스킬 대신 회사가 허용한 로컬 도구로 가리세요.
- 형식으로 찾는 방식이라 **이름, 주소, 회사명, 직급처럼 형식이 없는 정보는 놓칠 수 있습니다.** 가린 글을 넘기기 전에 사람이 한 번 읽고 확인하세요.

## 가리는 대상과 표시

| 종류 | 찾는 형식(예) | 표시 |
|---|---|---|
| 휴대전화, 일반 전화 | `010-1234-5678`, `01012345678`, `02-123-4567`, `+82 10 ...` | `[전화1]` |
| 이메일 | `name@example.com` | `[메일1]` |
| 주민등록번호, 외국인등록번호 형식 | `000000-0000000`(앞 6자리, 뒤 7자리) | `[주민번호1]` |
| 사업자등록번호 형식 | `000-00-00000` | `[사업자번호1]` |
| 카드번호 형식 | 4자리씩 4묶음(`0000-0000-0000-0000`, 띄어쓰기 포함) | `[카드1]` |
| 계좌로 의심되는 숫자 | 은행 이름이나 「계좌」, 「입금」 근처의 10~14자리 숫자나 하이픈 숫자 | `[계좌1]` |
| 이름(문맥상 분명할 때만) | 「홍길동 과장」, 「김OO님」처럼 호칭이 붙은 사람 이름 | `[이름1]` |
| 주소(문맥상 분명할 때만) | 「서울시 ... 로 12」처럼 도로명, 번지가 있는 주소 | `[주소1]` |

## 지킬 규칙

1. **같은 값은 같은 표시.** 같은 전화번호가 두 번 나오면 둘 다 `[전화1]`. 다른 값이면 번호를 올립니다(`[전화2]`).
2. **값 일부만 남기지 않습니다.** `010-****-5678`처럼 일부를 남기지 않고 통째로 바꿉니다. 일부 남기기는 사용자가 요청할 때만 합니다.
3. **글의 나머지는 한 글자도 바꾸지 않습니다.** 맞춤법, 띄어쓰기, 줄바꿈을 고치지 않습니다.
4. **의심스러우면 가리고 표에 표시합니다.** 주문번호인지 계좌인지 애매한 숫자는 가리고 되돌리기 표 「확인」 칸에 `애매함`이라고 씁니다.
5. **이름과 주소는 형식으로 다 못 찾습니다.** 문맥상 분명한 것만 가리고, 놓쳤을 수 있는 줄(사람이나 장소처럼 보이는 단어가 있는 줄)을 맨 끝 「직접 확인할 곳」에 적습니다.
6. **되돌리기 표는 따로.** 가린 글과 되돌리기 표를 서로 다른 코드 블록으로 줍니다. 되돌리기 표는 AI에 다시 붙여 넣지 말라고 한 줄로 안내합니다.
7. **되돌리기 요청.** 사용자가 AI 결과물과 되돌리기 표를 같이 주며 「되돌려 줘」라고 하면 표시를 원래 값으로 바꿉니다. 표에 없는 표시는 그대로 두고 알려 줍니다.

## 출력 형식

````
> 주의: (위 「꼭 알려 줄 것」 두 줄)

## 1. 가린 글 (이것만 AI에 넣으세요)
```
(가린 글)
```

## 2. 되돌리기 표 (내 컴퓨터에만 보관, AI에 넣지 마세요)
```
| 표시 | 원래 값 | 종류 | 확인 |
|---|---|---|---|
| [전화1] | ... | 전화 | |
```

## 3. 직접 확인할 곳
- (줄 번호나 짧은 인용) 이름이나 주소일 수 있음
````

## 예시

`예시/입력_고객메모.md`와 `예시/기대출력.md`를 참고합니다(모두 가상 데이터, 번호는 실제로 쓰이지 않는 형식의 예시값).
